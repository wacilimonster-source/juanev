华为 VCN3020 对接调用说明

组织树同步、摄像机同步与实时 RTSP 取停流

接口依据 eSDK IVS V200R019C50 客户端 API · 2026-11-04

目录 01 总体流程 02 SDK 登录 03 域与组织树 04 摄像机列表 05 实时取流 06 停流与注销 07 极星字段映射 08 联调验收 09 参考材料

01 总体流程

  1. 建立会话。 调用 IVS_SDK_Init 和 IVS_SDK_Login，获得 iSessionID。
  2. 同步组织。 调用 IVS_SDK_GetDomainRoute 获取授权域，以各域的 cDomainCode 查询设备组。按父组关系先建父组，再建子组。
  3. 同步摄像机。 调用 IVS_SDK_GetDeviceList 分页读取摄像机，按 cDomainCode 和 cDevGroupCode 查极星分组。
  4. 按需播放。 用摄像机 cCode 调用 IVS_SDK_GetRtspURL，将返回的 URL 交给 RTSP 客户端，在 30 秒有效期内发起连接。
  5. 结束播放。 关闭拉流客户端。本次 SDK 会话使用完毕后注销，进程退出时释放 SDK 资源。

CHM 概述列出的 VCN3020 配套版本为 V100R002C50SPC206。联调前核对现场固件、配套 SDK、账号可见范围以及 RTSP 实际访问地址。

02 SDK 初始化与登录

IVS_INT32 IVS_SDK_Init();
IVS_INT32 IVS_SDK_Login(IVS_LOGIN_INFO *pLoginReqInfo,
                        IVS_INT32 *pSessionID);

进程启动时调用一次 IVS_SDK_Init()。成功后将 IVS_LOGIN_INFO 清零，再填入以下字段，使用账号密码发起登录。

入参字段填法
stIP.uiIPType / stIP.cIPIPv4 示例使用 IP_V4 与平台 IP。
uiPort平台 SDK 登录端口，CHM 默认 9900，以现场配置为准。
cUserName / pPWD对接账号和密码。基本身份验证要求密码非空。
uiLoginType / uiClientType基本身份验证用 0。登录示例使用 uiClientType=0（PC 客户端）。

登录超时为 20 秒。返回码 0 表示成功，从输出参数读取 iSessionID。0 是合法会话 ID，SDK 的会话 ID 范围为 0–127，最多支持 128 个同时登录。后续业务调用复用有效会话。

收到 SDK 无效会话错误 IVS_SDK_RET_INVALID_SESSION_ID（999115312）时，重新登录并以新会话重试当前查询或重新申请取流。记录接口名和返回码，避免记录账号密码或完整取流 URL。同步若因会话或接口错误中断，保留既有数据，待完整同步成功后再核对缺失资源。

03 获取域与组织树

3.1 获取当前账号可见的域

IVS_INT32 IVS_SDK_GetDomainRoute(IVS_INT32 iSessionID,
                                 IVS_DOMAIN_ROUTE_LIST *pDomainRouteList,
                                 IVS_UINT32 uiBufferSize);

预分配并清零输出缓冲区，传入实际字节数。返回成功后检查 uiTotal 是否在容量内，再遍历 stDomainRoute[]。取 cDomainCode 作为设备组查询入参，取 cDomainName 作为域展示名。bIsLocalDomain 用于区分本域与外域，cSuperDomain 表示上级域。

域路由接口描述写明系统最多 128×8 个域，示例按 128 条分配。缓冲区大小按配套 SDK 头文件及确认的容量 N 计算，即 sizeof(IVS_DOMAIN_ROUTE_LIST) + (N - 1) * sizeof(IVS_DOMAIN_ROUTE)。联调核对实际域数和容量，超容量时中止本次同步并核查。

3.2 按父组关系还原设备组树

IVS_INT32 IVS_SDK_GetDeviceGroup(IVS_INT32 iSessionID,
                                 const IVS_CHAR *pDomainCode,
                                 const IVS_CHAR *pDevGroupCode,
                                 IVS_DEVICE_GROUP_LIST *pDeviceGroupList,
                                 IVS_UINT32 uiBufferSize);
  1. 每个目标域首次调用传入 pDomainCode = cDomainCode 和 pDevGroupCode = "0"。按接口要求预留 5000 条，缓冲区大小为 sizeof(IVS_DEVICE_GROUP_LIST) + 4999 * sizeof(IVS_DEVICE_GROUP)。
  2. 返回成功后，在缓冲区容量内按 uiTotal 读取 stDeviceGroup[]，保存 cGroupCode、cGroupName、cParentGroupCode、cDomainCode 和 bIsExDomin。
  3. 按 cParentGroupCode 挂接。父组为 "0" 时挂到该域的极星分组。联调用有多层组织的域确认根查询覆盖深度。若根查询只回直接子组，传每个子组 cGroupCode 逐层查询，以域和组编码去重。

04 分页获取摄像机

IVS_INT32 IVS_SDK_GetDeviceList(IVS_INT32 iSessionID,
                                IVS_UINT32 uiDeviceType,
                                const IVS_INDEX_RANGE *pIndexRange,
                                IVS_VOID *pDeviceList,
                                IVS_UINT32 uiBufferSize);
设备类型输出结构用途
2IVS_CAMERA_BRIEF_INFO_LIST基础同步默认使用，包含摄像机编码、名称、域、所属组和状态。
33IVS_CAMERA_BRIEF_INFO_LIST_EX需要经纬度时使用。
35IVS_CAMERA_BRIEF_INFO_LIST_V2需要互联编码 cConnectCode 时使用。以配套 SDK 头文件确认类型定义。
  1. 首查 IVS_INDEX_RANGE{1, 1000}。区间两端均包含，每页最多 1000 台。按实际类型分配缓冲区，类型 2 的计算方式为 sizeof(IVS_CAMERA_BRIEF_INFO_LIST) + (N - 1) * sizeof(IVS_CAMERA_BRIEF_INFO)，其中 N 为本页申请条数。
  2. 成功后读取 uiTotal 和返回的 stIndexRange。总数为 0 时结束。非空时先校验返回区间和本页容量，再读取 stCameraBriefInfo[]；最后一页最多读取总数覆盖的记录。
  3. 若返回区间尚未到达总数，从已确认的最后一个索引加一继续查询。总数 2003 时，正常请求依次为 1–1000、1001–2000、2001–2003。区间异常、缺页或无推进时，将本轮标记为未完成并复查。

归属匹配使用 cDomainCode 和 cDevGroupCode。cParentCode 表示父设备编码。uiStatus 的 0/1/2 分别为离线、在线、休眠；uiCameraStatus=2 表示视频丢失。资源同步保留离线摄像机。

如只需查询某个域，可用 IVS_SDK_GetDomainDeviceList 传入域编码和类型 2。该接口在 CHM 中列出的摄像机类型包含 2 和 33，使用 35 时走上面的 IVS_SDK_GetDeviceList。

05 申请 RTSP URL 并拉流

IVS_SDK_API IVS_SDK_GetRtspURL(IVS_INT32 iSessionID,
                               const IVS_CHAR *pCameraCode,
                               const IVS_URL_MEDIA_PARAM *pURLMediaParam,
                               IVS_CHAR *pRtspURL,
                               IVS_UINT32 uiBufferSize);

摄像机编码取设备列表的 cCode 原值。将 IVS_URL_MEDIA_PARAM 清零后填写实时播放参数，URL 输出缓冲区可按 CHM 示例先用 1024 字节，传入实际缓冲区字节数。

参数首轮联调取值含义
ServiceTypeSERVICE_TYPE_REALVIDEO（1）实时浏览。
StreamTypeSTREAM_TYPE_MAIN（1）主码流，辅码流 1 为 2。
ProtocolTypePROTOCOL_RTP_OVER_TCP（2）按 TCP 拉流联调时，拉流端也选 TCP。使用 UDP 时对应 PROTOCOL_RTP_OVER_UDP（1）。
PackProtocolTypePACK_PROTOCOL_ES一般先用 ES，国标摄像机按现场协商验证 PS。CHM 明确不支持 TS。
TransMode / BroadCastTypeMEDIA_TRANS（0） / BROADCAST_UNICAST（0）中转、单播。
iClientType1标准 RTSP 客户端。若联调涉及外域短 URL，CHM 指定使用 5，需验证现场支持。
VideoDecType / AudioDecType示例 VIDEO_DEC_H264 / AUDIO_DEC_G711U按设备码流和客户端解码能力填写。H.265 使用 VIDEO_DEC_H265。
dstIP默认留空NAT 场景按现场确认的目的 IPv4 填写。
 
// 示例使用支持 H.264 / G.711U 的摄像机和拉流客户端
IVS_URL_MEDIA_PARAM media = {};
media.ServiceType = SERVICE_TYPE_REALVIDEO;
media.StreamType = STREAM_TYPE_MAIN;
media.ProtocolType = PROTOCOL_RTP_OVER_TCP;
media.PackProtocolType = PACK_PROTOCOL_ES;
media.TransMode = MEDIA_TRANS;
media.BroadCastType = BROADCAST_UNICAST;
media.iClientType = 1;
media.VideoDecType = VIDEO_DEC_H264;
media.AudioDecType = AUDIO_DEC_G711U;

IVS_CHAR url[1024] = {};
IVS_INT32 ret = IVS_SDK_GetRtspURL(iSessionID, cameraCode, &media,
                                  url, sizeof(url));
// ret == 0 且 URL 非空时，立即交给 RTSP 客户端发起播放。

按需申请 URL，在 30 秒内发起连接。过期或重拉时重新申请并使用完整返回值。若 SDK 返回成功但客户端无法播放，依次核查 URL 中的媒体地址与端口、传输协议、编码和平台视频加密配置。CHM 明确提示，开启视频加密时，第三方无法解析该接口返回的 RTSP URL。

06 停流、注销与资源释放

  1. 业务结束时，由发起拉流的一侧执行客户端停止或关闭操作，释放本路 RTSP 连接和解码资源。联调观察客户端退出后 VCN3020 平台侧的播放会话何时释放。
  2. 该 SDK 会话的业务全部结束后调用 IVS_SDK_Logout(iSessionID)。成功后废弃旧会话 ID。其他调用仍在共用该会话时，保留会话。
  3. 进程退出前，在业务和会话结束后调用 IVS_SDK_Cleanup()，与初始化配对。

华为将 IVS_SDK_StopURLPlayByToken 标为仅适配 IVS3800 V100R019C50 及以上版本。VCN3020 的验收以拉流客户端关闭后的实际释放结果为准。若现场要求平台侧强制停流，由平台方确认该版本支持的接口及权限。

07 极星字段映射

8 北来源极星字段或映射处理方式
域 cDomainName / 组 cGroupNamename用作分组名称。
cDomainCode / (cDomainCode, cGroupCode)本地映射键分别保存域和设备组对应的极星分组 ID。
组 cParentGroupCodepid查到上级极星分组 ID 后填入；根组编码 "0" 关联对应域分组。
摄像机 cDomainCode + cDevGroupCodegroupId用组合键查极星分组 ID。组编码为 "0" 时对应域分组。归属缺失的设备先记录并核对源数据或权限。
摄像机 cCode / cNamecid / namecid 暂用 cCode 原值，联调验证跨域唯一性。若出现冲突，先确认极星唯一键规则，取流仍使用原始 cCode。
IVS_SDK_GetRtspURL 输出stream沿用视频地址字段的业务含义，播放时填入新申请的临时 URL。资源同步持久化摄像机标识和归属。

字段串联示例

域路由  cDomainCode = "DOMAIN_A"
设备组  cGroupCode = "GROUP_01", cParentGroupCode = "0"
摄像机  cCode = "CAM_01", cDomainCode = "DOMAIN_A",
        cDevGroupCode = "GROUP_01"

极星    groupId = 映射("DOMAIN_A", "GROUP_01"), cid = "CAM_01"
取流    GetRtspURL 的 pCameraCode = "CAM_01"，返回 URL 用于本次播放

08 联调验收

检查项验收观察
版本、权限、登录确认固件和配套 SDK，核对登录地址及端口。返回有效会话，账号可见域和设备符合授权范围。验证会话失效后的重新登录。
组织树选择有多层设备组的域，与平台管理界面核对节点数及父子关系。涉及多域时，检查同名组或同编码组的归属。
摄像机用较小页长或超过 1000 台的目录验证翻页和末页，核对总数、组归属、离线设备和 cid 唯一性。
实时播放抽测在线摄像机，验证在有效期内能收到画面，过期后重新申请可播放。记录实测协议、媒体地址端口和编码。
释放与重拉停止客户端后检查本地资源和平台侧会话，反复取流与停止，记录实际释放时长。若有外域设备，单列外域取停流结果。
