# 【智能巡视】智慧工地一体化平台与极视角接口文档

> 本文档基于智能巡视（smartpatrol）模块实际代码生成，对原《【景观恢复】智慧工地一体化平台与极视角接口文档》的入参与接口地址进行修订。

## 文档概述

本文档旨在定义智慧工地一体化平台与极视角之间的数据交互接口规范。双方通过 HTTPS 协议进行通信，数据交换格式为 JSON。

### 1\.1 系统环境地址

|**系统**|**环境**|**地址**|
|---|---|---|
|智慧工地一体化平台（智能分析服务）|预生产环境|https://zhgd\-pre\.qd\-metro\.com:8091/analyse|
||正式环境|https://zhgd\.qd\-metro\.com:8081/analyse|
|极视角|测试/正式环境|http://172\.27\.141\.170|

### 1\.2 通用约定

- **通信协议**： HTTPS

- **数据格式**： JSON

- **编码格式**： UTF\-8

- **下发接口（3\.1/3\.2）**： 裸 JSON 数组 POST，**不加签、不加密**

- **回调接口（3\.3）**： 加密加签传输，参考文档 [景观恢复\-jsj对外接口文档](https://qurt2019.feishu.cn/wiki/KfOmwUWGkiB8xPkKvqncZ5VsnJh)

- **通用响应码**：

    - 0：操作成功

    - 1：操作失败（具体原因见 msg 字段）

## 接口详情

### 3\.1\. 下发点位基础信息

- **接口说明**： 智慧工地平台调用此接口，下发拍摄点基础信息给低空平台。

- **请求方式**: POST

- **接口地址**: 

- **报文格式**： 裸 JSON 数组，不加签

#### 请求参数 \(Body\)

|**字段**|**类型**|**是否必填**|**说明**|
|---|---|---|---|
|pointCode|String|是|点位编码|
|pointName|String|是|点位名称|

**请求示例：**

```JSON
[
  {"pointCode": "QD-GD-TEST-001", "pointName": "模拟测试点位一（东川路站东南角）"},
  {"pointCode": "QD-GD-TEST-002", "pointName": "模拟测试点位二（东川路站东北角）"},
  {"pointCode": "QD-GD-TEST-003", "pointName": "模拟测试点位三（盾构井西侧）"}
]
```

#### 响应参数

|**字段**|**类型**|**说明**|
|---|---|---|
|code|int|状态编码|
|msg|String|说明信息|
|data|Object|响应数据对象|

**成功响应示例：**

```JSON
{ "code": 0, "msg": "新增成功", "data": null }
```

**失败响应示例：**


### 3\.3\. 接收点位识别结果（回调）

- **接口说明**： 此接口由**智慧工地平台提供**（智能分析服务 `SmartPatrolReceivePublicController`）。极视角完成识别后，主动回调此接口回写识别结果。

- **请求方式**: POST

- **接口地址**: `/analyse/public/smartPatrol/analysis/receive`

- **安全机制**： `/public/*` 路径由 `CheckSignFilter` 验签（免认证白名单），需加密传输，参考 [景观恢复\-jsj对外接口文档](https://qurt2019.feishu.cn/wiki/KfOmwUWGkiB8xPkKvqncZ5VsnJh)

|**字段**|**类型**|**是否必填**|**说明**|

|sign|String|是|签名|
|timestamp|String|是|时间戳|
|content|String|是|业务报文（Base64 编码，解码后为 UTF\-8 JSON）|

|**字段**|**类型**|**是否必填**|**说明**|

|**字段**|**类型**|**是否必填**|**说明**|

## 附录

### A\.1 taskType 场景定义

|编码|场景|
|---|---|
|1803|树木识别|
|1804|绿化面积|
|1805|硬化路面|
|1806|苗木绿化状态|
|1807|地面铺装状态|

### A\.2 响应参数说明 \(modelResult\)

> ⚠️ **重要约束**： `modelResult` 为 **JSON Object** 或 **JSON Array** 类型，**非字符串**。若识别失败或无目标，数值字段返回 `0` 或 `0.0`，数组字段返回空数组 `[]`，**不返回 null**。

#### A\.2\.1 目标检测类（taskType: 1803）

系统会遍历 JSON 中的绿化框，将每个框裁剪给大模型找树，并将小图中的相对坐标反算回原图的绝对像素坐标。

- `bbox_2d`： Array\<Integer\>，边界框坐标 `[左上x, 左上y, 右下x, 右下y]`，单位像素

- `label`： String，识别种类标签（如 `tree`）

#### A\.2\.2 区域百分比分析类（taskType: 1804 / 1805）

- 1804： `greenPercentage`（绿化覆盖率）

- 1805： `hardened_surfacePercentage`（硬化率）

累加所有划定区域的 `(Area × AI估算覆盖率)`，除以 `总划定Area` 得到真实百分比。

#### A\.2\.3 场景状态分类类（taskType: 1806 / 1807）

- `sceneStatus`： String，场景状态（如 `unconstructed` 未施工）

- `confidence`： Number，置信度

- `regionCoveredPercentage`： Number，区域覆盖率

逻辑同百分比计算，但增加了 95% 的达标阈值判定。
