三、同步规则

情况动作说明
视图有，平台没有新增用户名=USR_ID，姓名=USR_NAM，密码=账号小写 + @2026，角色=普通用户
视图有，平台已有同名「本地」账号跳过不覆盖本地账号，计入本次「跳过」人数
视图有，平台也有更新只更新姓名；密码、角色不覆盖。角色由管理员或超级管理员在平台上调整，同步不会改回去
平台有（同步来源），视图没有删除视为离职或调出，删除账号；若该账号正在登录，不强制下线，登录状态到期自然失效
平台本地账号（Administrator / Admin / test 等）不处理不参与同步，永远不会被修改或删除
账号增加「来源」属性：同步 / 本地。只有「同步」来源的账号才会被同步程序删除，手工创建的账号不受影响。上线前平台已有的账号统一标记为「本地」。

四、内置「普通用户」角色

  • 平台初始化时自动创建「普通用户」角色，作为同步账号的默认角色。
  • 该角色可编辑（管理员可调整菜单权限），不可删除（角色列表中不显示删除按钮），防止同步时找不到默认角色。
  • 同步新增的账号一律配置为「普通用户」；如需更高权限，由管理员在账号管理中单独修改，后续同步不会覆盖。

五、安全保护

  • 空数据不删除：数据库连接失败或视图返回 0 条数据时，本次同步终止，不改动任何账号。
  • 单条异常跳过：USR_ID 为空或不符合平台用户名校验规则的数据跳过，计入「跳过」人数并记入后台日志。
  • 数据库只读：只读取客户视图，不回写；账号密码加密存放在后端配置中。

六、账号与角色保护 2026.11.13 新增

对象规则
超级管理员角色系统内置，不可编辑、不可删除，角色列表中不显示这两个操作
管理员角色系统内置，不可删除；编辑权限维持现有页面逻辑不变
普通用户角色可编辑、不可删除（同步账号默认角色，见第四节）
同步账号不提供自助改密和角色编辑；需要改密码或调整角色时，由管理员在账号管理中操作，同步账号自身无法修改
「普通用户」角色不分配「用户管理」菜单权限，同步账号登录后看不到角色管理和账号管理页，自然不会出现自行提权或误删管理员的情况。账号角色统一由管理员或超级管理员调整，无需额外开发前端校验。

七、触发方式

  • 定时同步：每天 02:00 自动执行。
  • 手动同步：账号管理页点击「立即同步」。
  • 防重复：同步进行中「立即同步」按钮置灰并显示「同步中…」，手动与定时同步不会同时执行。
